# Login technology icons

The login page includes only the fourteen technologies approved in the design
preview, with TypeScript and TSX represented by one entry. Icons are served
locally; the page makes no requests to external icon services.

React, TypeScript, Vite, Vercel, Railway, Docker, HiveMQ, MQTT, Espressif (labelled
ESP32), PostgreSQL and Zod use SVG artwork from
[Simple Icons](https://github.com/simple-icons/simple-icons/tree/b86d5c9a0bdd4f3f5c30898a63654dd32f39fd76/icons),
commit `b86d5c9a0bdd4f3f5c30898a63654dd32f39fd76`, under its
[CC0-1.0 license](https://github.com/simple-icons/simple-icons/blob/b86d5c9a0bdd4f3f5c30898a63654dd32f39fd76/LICENSE.md).
The SVG fill colours match the approved preview. Brand names and marks remain
the property of their respective owners.

The Fluent UI layers, FreeRTOS chip/clock and WebSocket arrows are original
illustrative symbols from the approved preview, not official brand marks.
