# SmartFarm setup — one short file

Fill [private-setup/smartfarm_setup.txt](../private-setup/smartfarm_setup.txt). The current blank template is `smartfarm_setup.example.txt`.

Only your GitHub username and the HiveMQ host/username/password belong in this file. Leave the HiveMQ fields blank if the existing repository broker information should be reused. No project IDs, OAuth setup, deployment URLs, or staging forms are needed before coding.

See [section 4 of the plan](../IMPLEMENTATION_PLAN.md#4-required-accounts-services-credentials-and-input-worksheet). The AI handles generated/discoverable configuration and asks for hosting authorization only when needed.

Actual credentials stay in the ignored private copy. Keep the public example blank. Copy the template only if the private file does not already exist; never overwrite a filled file.
